How the algorithm works
01 — TOKENIZE
Split into tokens
Each document is split into words (or chars). These form sequences A[0..m] and B[0..n].
02 — FILL TABLE
Build DP matrix
For each pair (i,j): if A[i]=B[j], dp[i][j]=dp[i-1][j-1]+1. Else max(dp[i-1][j], dp[i][j-1]).
03 — TRACEBACK
Reconstruct LCS
Walk from dp[m][n] back to origin following the path of matches to recover the actual subsequence.
